# 컴포넌트 직접 편집 운영 안내

실제 배포 디자인의 소스는 `published-source/`, 편집 소스는 `src/published-editor/`에 있습니다. `npm run build`는 `dist-published/`를 만들고 Vercel도 이 폴더를 사용합니다. 기존 React 개발 화면과 `dist/`의 작업은 덮어쓰지 않습니다. `build:legacy`는 이전 생성 스크립트 보관용이며 현재 삭제된 정적 파일을 복원하지 않습니다.

## 편집

관리자 모드 → 로그인 → 홈페이지 컴포넌트 클릭 → 해당 문구·사진 편집 → 컴포넌트에 적용 → 홈페이지에 저장. 저장 전 변경은 현재 페이지에서만 보입니다. 취소하면 마지막 저장 상태로 돌아갑니다. 방문자 미리보기에서는 링크와 사진 갤러리를 원래처럼 사용할 수 있습니다.

대상은 메인, 교육과정 카드, 강사 카드 및 상세 프로필 영역, 시설, 수강료, FAQ, 과정 상세 페이지의 커리큘럼입니다. 수강료와 과정 카드의 공통 필드, 강사 이름·직함은 공통 데이터로 관리합니다. 강사 사진과 경력은 페이지별로 관리합니다. 교육과정 카드의 편집창에 커리큘럼 항목도 표시되며, 저장 후 과정 상세 페이지와 방문자 커리큘럼 팝업에 함께 반영됩니다.

## 로컬 검수

`npm run build` 후 `npm run preview:published -- --demo`를 실행하고 `http://127.0.0.1:4174`에서 확인합니다. 로컬 데모 비밀번호는 `preview-only`입니다. 데모 데이터는 서버 메모리에만 저장되며 재시작하면 사라집니다. 사진 파일 업로드는 운영 저장소 연결이 필요합니다. 운영 빌드에는 데모 인증이 포함되지 않습니다.

## 운영 연결

Vercel 서버 환경에 `ADMIN_PASSWORD`, 32자 이상 `ADMIN_SESSION_SECRET`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 설정합니다. 비밀키를 브라우저 변수로 노출하지 않습니다. Supabase에 `20261011_admin_cms.sql` 다음 `20261012_component_editor_security.sql`을 적용합니다. 후속 마이그레이션은 공개 CMS 쓰기·상담 조회·이미지 업로드 권한을 제거하고 서버 전용 저장 함수를 만듭니다.

저장소 미연결 시 저장 버튼은 비활성화됩니다. 실제 서버 저장과 사진 업로드, 다른 기기의 방문자 화면 반영은 운영 연결 후 확인해야 합니다. 이 작업에서는 외부 배포나 운영 데이터 변경을 실행하지 않았습니다.

## 2026-10-14 보안 보완 적용

운영 코드 배포 전에 기존 CMS 보안 마이그레이션과 `20261014_admin_sessions.sql`을 Supabase SQL 편집기에서 순서대로 적용하세요. 새 테이블과 함수가 없거나 저장소에 연결하지 못하면 관리자 로그인·조회·수정을 거부합니다. 운영 인증에 메모리 저장소로 우회하는 경로는 없습니다.

관리자 로그인은 IP별 15분 동안 5회, 전체 15분 동안 100회로 제한합니다. 성공한 로그인도 시도 횟수에 포함합니다. 제한 시 HTTP 429와 `Retry-After`를 반환합니다. Vercel에서는 플랫폼이 설정하는 `x-vercel-forwarded-for`를 사용하며 일반 프록시의 사용자 입력 헤더를 신뢰하지 않습니다. 다른 호스팅 환경에서는 직접 연결의 IP를 사용하므로 프록시를 추가한다면 신뢰 경계를 별도로 설정해야 합니다. IP는 HMAC 값으로 저장합니다.

세션 토큰 원문은 저장하지 않습니다. 관리자 API는 매번 서버 저장소에서 세션 유효성을 확인하며 로그아웃 시 해당 세션을 삭제합니다. 이전 형식 세션은 무효화되므로 다시 로그인해야 합니다. 관리자 비밀번호나 서명 비밀키를 변경하면 기존 세션도 무효화됩니다. 만료된 세션·제한 기록은 다음 로그인 요청에서 정리됩니다. `--demo`의 메모리 인증은 루프백 전용 미리보기 서버에서만 명시적으로 주입합니다.

이전 Firebase 연동을 쓰는 프로젝트가 있다면 수정된 `firestore.rules`를 해당 Firebase 프로젝트에도 적용하세요. CMS 읽기만 공개하며 CMS 쓰기와 상담 정보의 모든 브라우저 접근을 차단합니다. 이전 React 화면의 기본 비밀번호와 localStorage 관리자 인증·상담 정보 저장은 제거했습니다. Vite 개발 서버는 `127.0.0.1`에서만 엽니다.

이 변경은 로컬 코드와 운영 적용용 SQL·규칙을 준비한 것입니다. 실제 Supabase/Firebase 적용과 Vercel 배포 후 로그인 차단, 로그아웃 뒤 쿠키 재사용 거부, 일반 방문자의 상담 조회 거부를 운영 환경에서도 확인해야 합니다.
