# AI 상담과 관리자 작업실

## 개발된 화면

- 공개 홈페이지 하단의 `AI 상담`: 문의 안내와 관심 분야별 과정 추천
- `/admin/ai`: 관리자 답변 초안, 상담 요약, FAQ 제안, 홍보 글 초안, 실제 후기 편집
- 홈페이지 편집 도구의 `AI 작업실` 링크로 이동
- 관리자 결과는 수정·복사해서 사용하며 자동으로 게시하거나 발송하지 않음

## 로컬 시연

`npm run build` 후 `npm run preview:published -- --demo`를 실행합니다.
`http://127.0.0.1:4174/admin/ai`에서 로컬 전용 비밀번호 `preview-only`로 로그인합니다.
예시 불러오기 → 초안 만들기로 각 기능을 시연할 수 있습니다.

시연 모드는 로컬 서버의 `--demo` 실행 옵션으로만 활성화됩니다. 키가 없어도 동작하지만 **실제 AI 생성이 아닌 규칙 기반 예시 응답**입니다. 공개 운영 API에서는 자동으로 시연 모드로 전환하지 않습니다.

## 실제 AI 연결

1. 기존 관리자 인증과 Supabase 연결 설정을 완료합니다.
2. `supabase/migrations/20261019_ai_limits.sql`을 적용합니다.
3. 서버 환경에 `OPENAI_API_KEY`, `OPENAI_MODEL`을 등록합니다. `OPENAI_MODEL`에는 해당 계정에서 사용 가능한 Responses API 모델 ID를 입력합니다.
4. 변경된 소스를 배포한 뒤 공개 상담과 관리자 기능을 운영 환경에서 검수합니다.

비밀키에 `VITE_` 접두사를 붙이지 마세요. 브라우저로 키나 모델 설정을 내려보내지 않습니다. 키·모델·인증 저장소 설정이 없으면 연결 준비 중을 표시하며, 실패 시 접수나 답변이 완료되었다고 표시하지 않습니다.

## 자료와 처리 방식

교육과정은 `content/courses.json`의 확정된 6개 과정과 서버의 안내 문구를 사용합니다. 현재 AI의 자료 범위는 과정 소개와 전화 연락처입니다. 전체 FAQ 본문이나 CMS의 실시간 수정 내용은 자동 동기화하지 않습니다. 공개 전 승인된 안내 문구를 `api/ai-assistant.js`의 `knowledge()`에 갱신하세요.

입력은 요청 1회 단위로 처리하며 대화 이력·회원 문의 기록을 저장하거나 회원 계정에 연결하지 않습니다. 관리자 상담 요약과 FAQ 제안은 직접 붙여 넣은 자료를 대상으로 합니다. 담당자 전환은 전화 링크이며 상담 접수·발송 기능을 뜻하지 않습니다.

실제 AI 호출 전 OpenAI 전송 안내에 동의해야 합니다. 이름·전화번호 등 개인정보를 지운 자료로 사용하고, 실제 운영 전 운영자의 개인정보 안내에 외부 AI 처리 내용을 반영하세요. 서버는 요청 원문을 로그나 DB에 저장하지 않으며 Responses API에 `store:false`를 전달합니다. 외부 제공자의 데이터 처리 정책까지 저장이 없다고 보장하는 것은 아닙니다.

호출 제한은 DB에서 원자적으로 적용합니다: IP별 10분에 10회, 전체 24시간에 200회. IP 원문 대신 HMAC 해시를 사용합니다. 제한 저장소 오류 시 AI를 호출하지 않습니다. Vercel은 덮어쓰는 클라이언트 IP 헤더를 사용하고, 로컬은 소켓 주소를 사용합니다. 다른 프록시 환경은 배포 구조에 맞게 수정해야 합니다.

## 검수

`npm test`는 관리자 권한·입력 검증·출처 검사·동의·시연/운영 구분·외부 요청 형식·사용량 제한·DB 권한을 검증합니다. 실제 유료 API 호출은 자동 테스트에서 수행하지 않습니다.

OpenAI 연결 구현은 [공식 텍스트 생성 안내](https://developers.openai.com/api/docs/guides/text)를 참고했습니다.
