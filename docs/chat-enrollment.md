# 릴스에서 챗봇으로 수강 신청

릴스 프로필 또는 연결 링크: https://www.kactstar.com/?chat=1

이 주소는 행사 팝업 대신 챗봇을 바로 엽니다. 인사, 수강료·교육과정·위치 기본 안내 버튼과 ‘수강 신청하기’를 제공합니다. 기본 안내는 승인된 고정 문구로 즉시 표시하며 자유 질문은 기존 AI 연결 설정을 사용합니다.

신청은 `/api/course-application`에서 기존 비공개 `academy_inquiries`에 저장합니다. 관리자 홈페이지의 ‘문의 관리’에서 목적 ‘수강 신청’으로 확인합니다. 이름·연락처는 AI로 전송하지 않습니다. 실제 저장 확인 후에만 접수 완료를 표시하고 수강 확정과 구분합니다.

기존 Supabase 서버 연결, 관리자 세션 비밀키 및 `consume_academy_ai_attempt` RPC가 필요합니다. 공개 API는 서버 저장소를 통해서만 접근하며 기존 관리자 조회 권한을 유지합니다. 신청 처리와 연락이 끝난 기록은 안내한 보유 기간에 맞춰 운영자가 삭제해야 합니다.

검증: `node --test tests/course-application.test.cjs`, `npm run build`. 테스트는 저장소를 대체하여 실행하며 운영 신청 기록을 만들지 않습니다.
