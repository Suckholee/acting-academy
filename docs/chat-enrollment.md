# 인스타그램에서 상담 대기 등록

인스타그램 프로필·릴스 연결 주소: https://www.kactstar.com/apply?source=instagram

모바일에서 수강 목적 → 희망 과정 → 지역 → 이름·연락처·개인정보 동의 순서로 진행합니다. 접수 완료는 화면에 안내합니다. SOLAPI·SMS·외부 문자 발송은 사용하지 않습니다.

챗봇 주소 https://www.kactstar.com/?chat=1 에서도 ‘수강 신청하기’를 누르면 같은 신청 화면으로 연결됩니다.

`/api/course-application`은 기존 비공개 `academy_inquiries`에 `신규` 상태로 저장합니다. 관리자 화면에는 ‘상담 대기’로 표시하며, 선택한 목적·과정·지역·인스타 유입 경로를 함께 확인할 수 있습니다. 이름·연락처는 AI로 전송하지 않습니다.

실장용 명단: https://www.kactstar.com/?admin=1&waitlist=1 (관리자 로그인 필요). 상담 대기 필터를 기본으로 제공하며, 임도윤 실장이 직접 연락 후 ‘연락 중 / 상담완료’로 변경하고 메모를 저장합니다.

기존 Supabase 서버 연결, 관리자 세션 비밀키와 요청 제한 RPC를 사용합니다. 저장이 확인된 경우에만 접수 완료를 표시합니다. 실제 등록 확정은 상담 후 진행합니다. 보유 기간 안내에 따라 상담과 연락이 끝난 기록은 운영자가 삭제해야 합니다.

검증: `node --test tests/course-application.test.cjs tests/enrollment-flow.test.cjs tests/editor-entry.test.cjs`, `npm run build`.

## 관리자 모드와 예약 시간표

상단 **UI변경**은 홈페이지 편집, **상담관리**는 `/admin/admissions` 전용 관리 화면으로 연결됩니다. 상담관리에서는 리스트형과 일별 타임테이블형을 전환하고, 신청 → 비대면 상담 진행 → 대면 상담 진행 → 확정 상태를 관리합니다. 기존 신규/연락 중/상담완료 데이터는 각각 신청/비대면 상담 진행/확정으로 표시합니다.

`supabase/migrations/20261021_admissions_workflow.sql`은 비공개 워크플로 테이블과 트랜잭션 저장 함수를 추가합니다. 임도윤 실장의 대면 상담 날짜·시작 시간·소요 시간을 저장하며, 겹치는 시간은 DB 제약으로 차단합니다. 한국 시간 기준, 기본 60분이며 30~240분 선택이 가능합니다. 일정 예약 체크를 해제하면 해당 예약 시간을 비웁니다. 다른 창에서 이미 변경된 기록은 버전 검사로 덮어쓰지 않습니다.
