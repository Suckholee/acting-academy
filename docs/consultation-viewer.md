# 관리자 상담실

관리자 메뉴의 **상담실** 또는 회원 관리의 **상담방·일지 열기**에서 `/admin/consultation`으로 이동합니다. 기존 관리자 로그인을 공유합니다.

## 상담 흐름

1. **상담방 준비**: 수강생 이름, 전화번호, 방문 경로, 관심 과정, 상담 담당자, 참고사항을 입력합니다. 관심 과정에 맞는 자료가 기본 선택되며, 배정 페이지를 직접 조정할 수 있습니다. 준비한 방은 `상담 대기`로 남습니다.
2. **상담 진행**: 방의 `상담 시작`을 누르면 그 수강생에게 배정한 자료만 열립니다. `넘기기` 모드에서는 한 손가락 또는 마우스로 좌우로 밀어 넘깁니다. 짧은 드래그는 원위치로 돌아옵니다. 상하 이동, 두 손가락 확대, 마지막 페이지 바깥으로의 드래그로 잘못 넘기지 않습니다. 하단 점과 목차도 사용할 수 있습니다.
3. **페이지 필기**: `펜` 또는 `지우개` 모드에서 자료 위에 기록합니다. 색상·굵기·되돌리기를 제공합니다. 필기 모드와 넘기기를 분리해 필기 중 페이지가 넘어가지 않습니다. 펜으로 쓰는 도중 들어온 손바닥 터치는 무시합니다. 확대·화면 크기와 무관하게 페이지 좌표로 저장합니다.
4. **상담일지**: 목표·현재 경험, 상담 내용, 추천 과정·수강 계획, 후속 연락·다음 약속, 상담자 메모를 작성합니다. 상담 내용이 있어야 `상담 완료로 저장`할 수 있습니다. 상담 중 일지와 페이지 필기는 같은 수강생 방에 따로 저장됩니다.
5. **다시 열기**: 방 목록의 `이어서 상담` 또는 `상담 기록 보기`에서 기존 필기와 일지를 복원합니다. 자료는 방 생성 시의 버전에 고정되므로 공통 자료를 교체해도 기존 필기 위치가 달라지지 않습니다.

필기·일지는 입력 후 자동 저장하며 저장 상태와 `저장` 버튼을 표시합니다. 저장 실패 시 화면 안의 작성 내용을 유지하고 다시 저장할 수 있습니다. 저장하지 못한 상태에서 방을 나가는 동작은 막으며, 창 종료·새로고침에는 브라우저의 미저장 경고를 사용합니다. 다른 창에서 같은 방을 수정했으면 409 응답으로 덮어쓰기를 막고 작성 내용을 복사해 둘 수 있도록 안내합니다. 브라우저 저장소에 고객 정보나 필기를 보관하지 않습니다.

## 운영 전 데이터베이스 적용

기존 관리자 세션·Supabase 서비스 연결 외에 다음 마이그레이션을 운영 DB에 적용해야 합니다.

```
supabase/migrations/20261020_consultation_rooms.sql
```

`academy_consultation_rooms`는 수강생 정보, 고정 자료 버전과 배정 페이지, 페이지별 선 좌표, 상담일지, 진행 상태, 수정 버전을 저장합니다. RLS를 활성화하고 익명·일반 회원의 조회와 수정을 차단합니다. 데이터 접근은 기존 서버 관리자 인증을 거친 `/api/admin-consultation?resource=rooms`에서만 수행합니다. 서버는 입력 길이, 페이지 배정, 필기 좌표·분량과 상태를 검증하며, 수정 버전 조건을 사용해 동시 저장 충돌을 차단합니다. 개인 상담기록이나 통화 녹음을 외부 AI 서비스로 보내지 않습니다.

새 마이그레이션과 변경 코드의 운영 배포는 별도 적용 사항입니다. 로컬 시연 성공을 운영 저장 완료로 표시하지 않습니다.

## 자료 교체

로컬에서 승인된 세로형 PDF를 가져옵니다. Python `pypdf`와 Poppler의 `pdftoppm`이 필요합니다. 페이지 수·목차가 바뀌면 가져오기 스크립트의 `titles`도 갱신합니다.

```sh
python3 scripts/import-consultation.py /절대경로/상담자료.pdf
npm run build
node --test tests/admin-consultation.test.cjs tests/consultation-rooms.test.cjs tests/consultation-gestures.test.cjs
```

`private-assets/consultation/`의 현재 PDF·페이지 이미지·목차 및 `versions/`를 함께 배포합니다. 버전별 파일은 가져오기 시 보존합니다. 기존 상담방이 참조하는 버전을 지우면 해당 방의 자료가 열리지 않습니다. 자료를 공개 정적 출력 폴더에 복사하지 않습니다. `vercel.json`의 함수 `includeFiles`가 서버 함수에 파일을 포함시키며, 원본 PDF의 내부 이동 링크와 전화 연결도 목차에 추출합니다.

## 로컬 시연

```sh
KJT_PREVIEW_PORT=4186 npm run preview:published -- --demo
```

이 컴퓨터의 `http://127.0.0.1:4186/admin/consultation`에서 테스트합니다. 시연 관리자 비밀번호는 `preview-only`입니다. 실제 고객 정보는 시연에 입력하지 않습니다. 상담방 시연 데이터는 Git에서 제외한 `output/consultation-demo/rooms.json`에 저장해 서버 재시작 후에도 유지됩니다. 시연 로그인 세션은 메모리 기반이므로 서버를 재시작하면 다시 로그인해야 합니다. 운영 API는 이 파일 저장소를 불러오지 않습니다.

검증은 실제 고객 대신 시연 자료로 수행합니다. 상담방별 정보 격리·자료 버전 보존·상담 완료·동시 저장 충돌·RLS·인증·스와이프 방향·다중 터치·펜 좌표 및 취소·복원·되돌리기를 테스트합니다. Apple Pencil 기기별 필압이나 손바닥 접촉 특성은 실제 태블릿에서 추가 확인할 수 있습니다.
