# 원장·대표 인사말 구성 근거

2026-10-20 사용자 요청: 다른 사이트의 원장·대표 인사말 구조를 분석하고, 우리 가치관에 맞는 내용으로 초안을 작성. 이성구 대표는 사진 없이 이름·직함 반영.

## 참고한 공식 페이지

- [액팅코드 인사말](https://actingcode.kr/인사말/): 교육 철학을 먼저 보여주고, 원장 인사와 교육 방식, 수강생을 향한 환영, 서명으로 연결하는 구조.
- [스피치앤리치 아카데미 소개](https://speechnrich.co.kr/about-academy/): 핵심 메시지에서 시작해 인사말, 교육 방향과 실전 연결, 운영 의지, 서명, 강사진 소개로 연결하는 구조.

두 사이트는 내용의 복제 대상이 아니라 정보 순서와 역할 분리를 검토하기 위한 참고 사례다. 소개 문장은 회의에서 합의한 기초·직접 연기·피드백·개인의 속도 존중을 바탕으로 새로 작성했다. 참고 사이트의 경력·성과·취업 관련 약속은 사용하지 않았다.

## 적용한 구조

| 위치 | 역할 | 내용 |
|---|---|---|
| 아카데미 철학 | 공동의 방향 | 진심으로 연기하고 나답게 성장한다는 기존 소개 |
| 김정태 원장 인사말 | 교육 철학 | 자기만의 표현, 몸과 목소리의 기초, 장면 실습과 구체적 피드백, 출발점의 다양성 |
| 이성구 대표 인사말 | 운영 가치 | 수강 목적을 듣는 안내, 배움에 집중하는 환경, 존중하는 소통, 지속적인 성장 |
| 세 가지 약속 | 한눈에 보는 핵심 | 기초부터 탄탄하게 / 직접 연기하며 / 나의 속도에 맞게 |
| 교육과정 연결 | 다음 행동 | 과정·희망 시간·기본 예상 수강료 확인과 전화 상담 |

각 인사말은 ‘핵심 한 문장 → 인사 → 가치관 → 실천 방향 → 환영·약속 → 이름·직함’으로 구성했다. 원장 작품 목록은 인사말 영역에 두지 않았다. 이성구 대표의 사진이나 경력은 임의로 만들지 않았다.

## 관리 및 검토

- 본문 초안 원본: `content/leadership.json`. 정적 생성: `scripts/build-leadership.cjs`.
- 아카데미 소개에서 원장(`#director`)과 대표(`#representative`) 인사말을 관리한다. 기존 `/trainers/kim-jung-tae` 주소는 원장 인사말로 이동한다.
- 강사 목록 및 메인·소개 페이지의 강사 카드에서는 김정태 원장을 제외하고 김형민 → 임도윤 → 편보승 순서로 구성한다.
- 사용자 요청에 따른 초안이며 실제 당사자의 발언을 인용한 글이 아니다. 공개 배포 및 운영 CMS 저장값 수정은 별도다.

## 수강료·시간 선택 화면

- 목적 → 관심 과정 → 기간(1~3개월) → 그룹/개인 레슨 → 월~일 희망 시간의 순서다.
- 기본 교습비 월 40만 원 기준: 1개월 40만 원, 2개월 80만 원, 3개월 10% 할인 108만 원.
- 프리미엄 과정 또는 개인 레슨 선택 시 ‘별도 상담’으로 표시한다. 정원 수에 따른 임의 가격을 만들지 않는다.
- 09~12 / 12~15 / 15~18 / 18~21 시간 블록은 희망 시간이며 실제 개설 또는 예약이 아님을 표시한다.
- 선택 조건은 화면 참고용이며 저장·전송하지 않는다. 전화 상담 시 직접 전달하도록 안내한다.
- 기존 교습비 기준표를 유지한다. 계산 결과는 인라인 문구 편집 대상에서 제외한다.
