# AI 오디션

공개 화면 `/ai-audition`, 관리 화면 `/admin/audition`.

로그인 없이 크롬에서 카메라로 사진을 촬영하거나 저장된 얼굴 사진 한 장을 선택하고 작품을 고른다. 촬영 버튼을 눌렀을 때만 전면 카메라 권한을 요청하며 마이크는 요청하지 않는다. 미리보기에서 사진 찍기를 누르면 좌우 방향을 미리보기와 맞춘 JPEG를 생성해 기존 사진 입력으로 사용한다. 촬영·닫기·지우기·파일 선택·탭 숨김·페이지 이탈 시 카메라 트랙을 종료한다. 권한 거부·장치 없음·사용 중 오류는 사진 선택 대안과 함께 안내한다. 카메라 영상 자체는 서버로 전송하지 않는다. 작품별 영화 장면과 교체할 인물의 얼굴 영역은 미리 등록되어 자동으로 불러온다. 사진 전송 동의를 확인하고 합성 버튼을 누르면 생성한다. 장면이나 얼굴 영역이 없는 작품은 합성을 시작할 수 없다. 작품을 변경해도 내 얼굴 사진은 유지하며, 지우기는 개인 사진과 결과만 지운다. 결과는 실제 사진 형태이며 웹툰 생성이나 연기 영상 심사 기능이 아니다.

얼굴 사진과 장면 사진을 브라우저에서 최대 1280px JPEG로 정규화한다. EXIF 등 원본 메타데이터는 전송하지 않는다. 입력당 900KB 이하, 전체 요청 3MB 이하로 제한한다. 공개 이용자에게 장면 업로드나 얼굴 영역 지정은 요구하지 않는다. 관리자가 장면 사진과 함께 정규화된 얼굴 위치·크기를 등록하고 미리보기에서 확인한다. 장면 이미지는 첫 번째 입력, 인물 사진은 두 번째 입력이며 서버에서 얼굴 영역을 머리·목 주변까지 확장한 PNG 마스크를 함께 Images Edit API에 보낸다. 기본 모델은 `OPENAI_IMAGE_MODEL` 또는 `gpt-image-2`다. 원본 구도·배경·다른 인물·의상·자세를 유지하도록 지시하지만 생성 모델의 결과이므로 완전한 픽셀 보존을 보장하지 않는다.

사진과 합성 결과는 저장소에 업로드하지 않고 요청 메모리와 현재 브라우저 화면에서만 처리한다. 내려받기는 현재 결과를 이용자 기기에 저장한다. 새로고침이나 지우기로 개인 사진과 화면 결과를 비운다. 요청·응답 본문을 로깅하지 않는다. OpenAI의 별도 보관 정책은 사이트 미보관과 구분해 처리 안내에 표시한다. API 키는 서버에서만 사용한다.

사진 전송 동의와 본인 사진 또는 사진 속 인물의 이용 허락 확인을 각각 받는다. JPEG·PNG·WEBP만 허용하며 외부 이미지 URL을 공개 합성 API에 받지 않는다. 입력값·동의·동일 출처와 스크립트 ID를 검증한 뒤에만 모델을 호출한다. 합성 요청 1회에 영속 제한을 한 번만 적용한다. 이미지용 익명 방문자 버킷을 텍스트 상담과 분리하여 방문자당 10분에 10회까지 요청할 수 있으며, 기존 데이터베이스의 서비스 전체 하루 200회 한도도 유지한다. 제한 응답은 Retry-After와 남은 초를 제공하고, 화면은 대기 시간을 표시하며 요청 버튼을 잠시 잠근다. 사진·작품·동의는 유지하고 대기 후 버튼만 다시 활성화한다. 자동 재요청은 하지 않는다. AI 처리 실패나 제한은 생성 완료로 표시하지 않는다. 시연 서버에서는 선택 사진을 반환하며 실제 합성이 아님을 명시한다.

초기 자료는 사용자가 지정한 블로그에서 확인한 네 작품의 아주 짧은 인용과 별도 작성한 연습 설명이다. 원작 전체 대사나 장면을 재현했다고 표기하지 않는다. 베테랑·친절한 금자씨는 CJ ENM 작품 소개, 봄날은 간다는 한국영상자료원 작품 소개, 올드보이는 KINO Rotterdam 상영 자료의 영화 장면 사진을 출처와 함께 등록했다. 각 인물의 얼굴 영역은 관리자가 미리 지정한다. 작품의 대표 장면이며 짧은 인용 대사의 정확한 프레임으로 단정하지 않는다. 출처 표기는 별도 이용 허락을 받았다는 뜻이 아니다. 현대 작품의 긴 대사와 사진은 공개 제공·AI 합성·결과 다운로드에 사용할 수 있는 자료를 관리자가 확인해 등록한다. 비영리만으로 사용 허락이 있다고 자동 판정하지 않는다.

관리자는 기존 로그인으로 작품명·작가 표기·원문 대사·출처·장면 사진·연습 설명과 이용 범위를 입력하고 공개 목록에 저장한다. `academy_cms`의 `audition-public-scripts` 키에 **공개 자료만** 저장한다. 이 테이블은 공개 읽기 대상이므로 계약서·개인 연락처·비공개 메모를 넣지 않는다. 회원 사진은 이 카탈로그에 저장하지 않는다. 저장 버전을 비교해 동시 수정 덮어쓰기를 막는다.

원전 대사 자동 수집, 이용자 요청 시 장면 자동 검색, 얼굴 인식·인증, 가입·유료 결제, 합격 예측, 제출 영상 평가, 개인 합성 이력 저장은 포함하지 않는다.

검증: 입력·동의·외부 출처 차단, API 입력 이미지 순서·마스크·결과 형식, 비용 제한, 관리자 인증·이용 범위 확인·동시 수정 보호 테스트. 가상 인물과 가상 촬영 장면을 이용한 최초 검증에 이어, 운영 홈페이지에서 등록된 올드보이 장면과 가상 인물 사진으로 실제 합성을 완료하고 사진·대사지 다운로드를 확인했다. 모바일 390px·360px에서 이미지 로딩과 가로 넘침이 없는 것을 확인했다.

카메라 검증: 전체 193개 검사 통과. 크롬의 가상 영상 입력에서 640×480 JPEG 촬영과 카메라 트랙 종료 표시를 확인했다. 실제 물리 카메라는 자동으로 켜지 않았으며 권한 거부·늦은 권한 응답·연결 끊김은 별도 검사했다. 모바일 390px에서 촬영 버튼과 가로 넘침을 확인했다.

공식 API 참고: https://developers.openai.com/api/reference/resources/images/methods/edit

연결 오류 처리: 크롬 `ERR_NETWORK_CHANGED`로 요청이 끊긴 사례를 확인했다. 전송 실패는 한국어로 안내하고 기존 사진·작품·동의를 유지한다. 오프라인에서는 합성 시작을 막고 연결 복구 후 다시 사용할 수 있다. 유료 합성을 자동으로 재요청하지 않는다.

## 공개 서비스 동시 이용

서명된 익명 쿠키로 방문자를 구분한다. IP 주소가 바뀌어도 같은 방문자의 요청은 유지되고 다른 방문자는 별도로 집계된다. 이용자당 진행 중인 요청은 하나이며 다른 탭에서 중복 생성하지 않는다.

기존 비공개 `academy_ai_limits` 테이블에 `audition-user:`, `audition-queue:`, `audition-slot:`, `audition-charge:` 이름 공간으로 식별자·상태·만료 시간만 기록한다. 원본 사진과 결과 이미지는 기록하지 않는다. PostgREST 원자적 INSERT 충돌 처리와 조건부 PATCH로 처리 슬롯을 확보한다. 기본 동시 처리 수는 3이며 `AUDITION_CONCURRENCY`로 1~8 범위에서 조절한다. 대기열의 먼저 들어온 요청부터 빈 슬롯을 얻는다. 대기 중에는 작은 상태 요청만 보내며 사진은 전송하지 않는다.

대기 갱신은 60초, 사진 전송 전 슬롯은 45초, 실행 슬롯은 270초 후 만료된다. 닫힌 탭의 대기 요청은 취소 신호와 만료 처리로 정리한다. 오래된 작업이 새 슬롯을 해제하지 못하도록 요청별 값을 비교한다. 큐 대기는 최대 30분이며 자동으로 재시도하지만 사용자는 취소 후 사진을 유지할 수 있다. 사진 생성 서버의 명시적인 429 응답은 같은 요청 번호로 최대 세 번 더 연결하며 생성 한도는 다시 차감하지 않는다. 모델 생성이 시작된 요청은 중복 실행하지 않는다.

사진은 현재 브라우저에만 있으므로 새로고침하면 사라진다. 결과 이력이나 네트워크 단절 후의 영구 복구 기능은 제공하지 않는다. 외부 제공자의 처리 한도와 하루 전체 200회 예산 한도는 유지한다. 무제한 동시 이미지 생성을 보장하는 구조가 아니다.


## 장면 확장과 사진 구도 추천 (2026-11-03)

기존 4편에 극한직업·광해, 왕이 된 남자·기생충·써니·국제시장·명량을 추가해 기본 10편을 제공한다. CJ ENM 공개 작품 사진을 로컬 자산으로 등록했으며 각 얼굴 영역을 직접 확인했다. 대사는 작품별 참고 기사에서 확인한 한 줄의 짧은 인용이고 상황 설명과 3단계 연습 안내는 별도로 작성했다. 사진은 대표 장면으로, 인용 대사의 정확한 프레임과 일치함을 뜻하지 않는다.

사진을 선택하고 두 동의 항목을 모두 확인하면 추천을 한 번 자동 실행한다. `gpt-4.1-mini` (`OPENAI_AUDITION_RECOMMEND_MODEL`로 변경 가능)의 Responses API, `store:false`, 엄격한 JSON 출력으로 사진의 얼굴 수·방향·기울기·프레이밍만 관찰한다. 관찰 결과와 미리 정리한 장면 구도를 서버에서 비교하여 한 장면을 고른다. 이름·외모 평가·나이·성별·인종·성격·연기 실력이나 캐스팅 적합성은 추천 기준이 아니다. 얼굴이 불분명하거나 여러 명이면 억지로 추천하지 않고 다시 촬영하거나 직접 선택하도록 안내한다. 장면 사진이나 영역을 관리자가 변경한 경우 기존 구도 정보는 적용하지 않는다.

추천 사진과 관찰 결과는 저장하지 않으며 요청 본문을 로깅하지 않는다. 사진 변경·지우기·동의 철회 시 이전 추천 요청을 중단하고 늦은 응답을 버린다. 추천 중 다른 작품을 고르면 수동 선택을 유지한다. 추천 서버 실패 시 직접 선택과 합성은 계속 이용할 수 있다. 추천을 다시 받는 것은 이용자가 버튼으로 요청하며, 추천 실패를 자동으로 반복 호출하지 않는다. 추천도 합성과 같은 영속 요청 한도(방문자당 10분 10회, 서비스 전체 하루 200회)에 포함한다. 추천은 사진 분석 비용이 별도로 발생하며 합성 이미지 생성은 이용자가 합성 버튼을 눌러야 시작한다.

추천 구조는 향후 장면이 늘어나도 사진 관찰 한 번과 서버의 장면별 비교로 동작한다. 새 작품을 추가할 때에는 얼굴 구도 프로필도 함께 검수한다. 감정이나 원하는 장르 같은 이용자 선택 조건은 현재 버전에 포함하지 않는다.


## 긴 대본·장면 유형·역할별 사진 (이전 대본 내용 철회)

기본 10편의 한 줄 대사를 각각 약 800~900자 창작 연습 대본으로 교체했다. 독백 3편, 1:1 대화 6편, 3인 장면 1편이며 유형 필터로 찾을 수 있다. 상황·역할·상대 대사·지문·세 단계 연습 안내를 제공한다. 대본의 A/B/C 역할을 골라 자기 대사를 강조하며, 다운로드와 인쇄에는 전체 대사가 포함된다. 약 1~2분은 읽는 속도와 호흡에 따라 달라지는 참고 분량이다. 이 대본은 해당 영화의 원문·실제 장면 대사를 옮기거나 이어 쓴 자료가 아님을 화면과 다운로드에 표시한다.

장면별 `cast`에는 최대 세 역할의 얼굴 위치를 등록한다. 내 사진을 넣을 역할을 바꿀 수 있고, 다른 역할에는 친구 사진을 선택적으로 넣는다. 친구 사진마다 합성과 OpenAI 전송에 대한 당사자 동의를 확인해야 합성을 시작할 수 있다. 사진이 없는 역할은 원본 얼굴을 기준으로 생성하며 세부 변화가 생길 수 있다. 작품 변경 시 친구 사진을 비워 다른 인물에게 의도치 않게 재사용하지 않으며, 내 사진은 유지한다. 지우기는 모든 개인 사진과 결과를 지운다. 관리 화면에서 B/C의 인물 이름과 얼굴 영역을 등록·수정할 수 있으며, 장면 사진을 바꾸면 추가 영역을 재설정한다.

새 다중 인물 요청은 역할 ID와 동의한 사진만 전송한다. 서버는 등록한 얼굴 위치를 기준으로 마스크를 새로 만들고, 사진을 올린 역할의 영역만 투명하게 한다. 첫 입력은 원래 장면이고 이후 참조 사진들은 역할별로 연결한다. 사진이 없는 역할은 참조 입력과 편집 마스크에 넣지 않는다. 최대 세 얼굴을 한 번의 이미지 편집 요청으로 처리하고 생성 한도도 한 번만 소비한다. 친구 수에 따라 입력 이미지 비용이 늘 수 있다. 인물 사진은 브라우저에서 최대 약 430KB로 줄이고, 장면 900KB·전체 요청 3MB 한도를 유지한다. 대기 중에는 친구 사진도 서버로 보내지 않는다. 친구 사진은 추천에는 사용하지 않는다.

2026-11-05부터 얼굴 영역을 원본 위에 잘라 붙이는 처리를 제거했다. 생성된 전체 이미지를 그대로 표시하고 JPEG로 내려받는다. 사진이 없는 역할은 보호 영역과 생성 지시로 원본 유지를 요청하지만 픽셀 보존을 보장하지 않는다. 이 처리는 개인 사진이나 결과를 영구 저장하지 않는다. 이전 브라우저의 단일 사진 요청은 계속 지원한다.


## 영화 원문 기준으로 정정 (2026-11-03)

사용자 요청은 실제 영화의 긴 장면 대사와 장면 사진을 미리 함께 등록하는 것이었다. 영화와 연결해 새로 작성했던 창작 대본 10편은 공개 카탈로그와 브라우저 번들에서 제거했다. 기본 템플릿은 확인된 짧은 인용만 참고용 접힌 영역에 보관하며, 장면 전체 원문 대본이 미등록임을 명시한다. 이를 긴 대본으로 오인하지 않도록 대사지 다운로드를 비활성화하고, 1~2분 분량 및 독백·대화 유형에 대한 표기도 제거한다. 등록된 실제 대본이 있을 때만 대본에 근거한 유형과 역할별 읽기·다운로드를 제공한다. 사용자 제공 원문은 임의로 대사를 새로 쓰지 않고 보존한다.

원문 대본과 이미지의 한 세트 등록에는 실제 장면의 상황·화자·대사·지문, 장면 사진, 사진 속 역할 위치가 필요하다. 내 사진과 친구 사진의 선택적 합성 및 미선택 얼굴의 원본 유지는 그대로 지원한다. 긴 영화 원문을 확보해 등록하는 작업은 사용자 제공 대본이 필요한 상태이며 완료로 표시하지 않는다.

## 첨부 대본 등록·이미지 기반 추천·링크 전용 진입 (2026-11-03)

사용자가 올린 네 장의 대본 이미지를 스타트업 독백, 미쓰 홍당무(두 이미지 연속), 이번 주 아내가 바람을 핍니다(두 이미지 연속)의 세 발췌로 전사했다. 대사는 `script`에 제공 순서대로 보존하고, 읽기용 화자·지문 매핑은 별도 `turns`에 보관한다. `turns`의 모든 문장은 원문 안에 같은 순서로 존재해야 하며 새 대사를 추가할 수 없다. 공개 화면과 다운로드는 제공된 발췌 전체를 표시한다. 공식 대본 전체가 아닌 첨부본이라는 점을 표시하고, 짧은 스타트업 발췌도 임의로 늘리지 않는다. 새 유형 `user-provided`는 사용자가 제공한 자료임을 기록하며 소유권이나 이용 허락을 임의로 단정하지 않는다.

사진은 tvN 3회 보도 사진, TVING 작품 사진, JTBC 8회 공식 클립 썸네일을 등록했다. 스타트업 보도 사진은 여러 프레임이 세로로 붙은 이미지여서 원본 파일을 보존한 채 브라우저에서 첫 프레임만 정확히 잘라 사용한다. 미쓰 홍당무 사진에는 미숙만 보여 사진 합성 대상도 미숙 한 명이며, 대본의 서 선생 응답은 그대로 표시한다. JTBC 사진은 준희·현우 두 얼굴을 각각 선택할 수 있다.

추천은 대본이 있는 세 장면을 우선 대상으로 한다. 단일 얼굴 확인 이후 보이는 표정·스타일·옷차림·이미지 분위기와 각 장면의 상황·감정 흐름을 함께 보고 장면 ID를 고른다. 각도 일치만으로 추천하지 않고 대본 없는 한 줄 인용 템플릿은 추천에서 제외한다. 신원, 나이·성별·인종, 실제 성격·능력·채용·캐스팅 결과를 판단하는 기능은 아니다. 개인 사진과 관찰 결과는 저장하지 않는다.

공개 공통 메뉴·홈페이지 홍보 영역·공개 버튼의 AI 오디션 링크를 제거했다. 직접 주소 `/ai-audition`은 유지하고 해당 페이지·API에 검색 제외 메타/응답 헤더를 적용하며 사이트맵에서 제외한다. 로그인 제한을 추가한 것은 아니므로 링크를 아는 사람은 이용할 수 있다. 관리자 화면의 관리 링크는 유지한다.


## 장면 맥락 재생성 (2026-11-05)

얼굴 사각형만 원본 위에 붙이던 브라우저 후처리를 제거했다. 이미지 편집 요청 안에서 원본 장면의 구도·시선·표정·조명·색온도·심도·질감과 각 참조 사진의 얼굴 특징을 함께 살펴보고, 선택 인물의 머리카락 경계·귀·턱·목·접촉 그림자까지 일관되게 재생성하도록 지시한다. 별도의 분석 API 호출을 추가한 것은 아니며 기존 모델, 품질 설정, 생성 1회당 한도와 동의 흐름을 유지한다.

단일 인물도 역할 ID와 사진으로 전송하며 서버에 등록된 좌표를 사용한다. 서버 마스크는 얼굴 좌우 20%, 위 25%, 아래 40%의 여유를 두고 바깥 20% 구간의 투명도를 부드럽게 연결한다. 사진을 넣지 않은 다른 인물의 얼굴과 8% 여유 영역은 편집 영역과 겹치더라도 보호한다. 마스크는 생성 지침이며 보호 영역의 결과가 원본 픽셀과 같음을 보장하지 않는다. 기존 브라우저의 단일 요청은 등록된 역할 좌표와 일치할 때 지원하고 전달된 마스크를 그대로 사용하지 않는다.

완성 결과는 다시 자르거나 리사이즈하지 않고 서버가 반환한 JPEG 그대로 표시·다운로드한다. 화면과 사진 처리 안내에서 배경·다른 인물의 세부 모습이 원본과 조금 달라질 수 있음을 안내한다. 실제 자연스러움과 본인 유사도는 참조 사진, 촬영 방향과 장면마다 달라지므로 자동 검사만으로 품질 향상을 확정하지 않는다.

## 사진·대사지 공유 카드 (2026-11-06)

생성 결과의 기본 화면을 사진과 대사 전체를 담은 한 장의 PNG 카드로 바꿨다. 짙은 배경·금색 포인트, 작품명과 장면 제목, 원본 비율을 유지한 생성 사진, 읽기 쉬운 밝은 대사지, 학원명과 주소 순서로 배치한다. 사진 오른쪽 아래에 `김정태 배우아카데미` 워터마크를 반투명 흰색으로 그리고, 카드 상단과 하단에도 학원명을 넣는다. 워터마크는 미리보기 위의 장식이 아니라 저장되는 이미지 픽셀에 포함된다.

대사는 `script` 원문 전체를 사용하며 줄바꿈만 조정한다. 긴 대사를 생략하거나 여러 이미지로 나누지 않고 카드 높이를 늘린다. 기본 너비는 1080px이며 극단적으로 긴 내용은 모바일 캔버스 한도 안으로 비례 축소한다. 원문 미등록 작품은 짧은 인용임을 카드에 명시한다. 생성 결과에는 AI 연습 이미지라는 안내를, 시연 모드에는 시연 이미지라는 안내를 넣는다.

`사진 + 대사지 이미지 저장`은 미리보기와 같은 PNG를 저장한다. 파일 공유가 지원되는 기기에서만 `이미지 공유`를 보여주고, 클릭 즉시 미리 준비한 파일로 기기의 공유 창을 연다. 취소하면 이미지를 유지하며, 미지원·실패 시 이미지 저장으로 직접 첨부할 수 있다. 결과의 인쇄 버튼은 제거하고 사진만 저장·대사지 텍스트 저장·역할 연습은 접힌 보조 영역에 둔다. 공유 카드 준비 실패는 사진 생성 성공을 취소하지 않으며 카드만 다시 만들 수 있다.

추가 AI 호출·사진 업로드·서버 저장 없이 브라우저에서 처리한다. 작품 변경·사진 지우기·새 생성 시 이전 카드 URL을 해제하고 늦게 도착한 카드 결과를 버린다. 사진만 저장하는 기존 JPEG는 생성 원본 그대로 제공하며, 카드의 워터마크는 통합 PNG에 적용한다.

## 연기 영상 카드 (2026-11-06)

공유 카드 아래에서 실제 목소리를 녹음해 사진·대사·워터마크와 함께 영상으로 저장한다. `voice-video.js`는 기존 카드 이미지를 캔버스에 그리고 마이크 스트림을 합쳐 MediaRecorder로 인코딩한다. 사진 속 인물을 움직이거나 음성을 합성하지 않으며, 녹음·영상 제작은 AI 호출·서버 업로드·회원 기록 저장 없이 브라우저 안에서 처리한다. 최대 2분, 45MB 제한으로 녹음을 종료하고, 카드 전체 비율을 유지하며 최대 1080×1920 범위 안으로 맞춘다. 브라우저가 지원하면 H.264/AAC MP4를 우선 사용하고 WebM으로 대체한다.

`녹음 시작 → 대사 읽기 → 녹음 끝내기 → 미리보기 → 영상 저장/영상 공유` 흐름이다. 녹음 중에는 타이머와 종료 버튼이 화면 아래에 고정되어 대사를 스크롤해도 종료할 수 있다. 파일 공유가 지원되면 준비된 File로 공유 창을 열고, 지원되지 않으면 다운로드한다. 실제 외부 앱 전송은 이용자가 선택한다. 녹음 지우기·다시 녹음하기를 제공하며 새로고침·장면 변경 전에 기기에 저장해야 한다.

권한 요청 중 취소 후 늦게 도착한 스트림, 녹음 오류, 결과 초기화, 화면 비활성화와 페이지 이탈에서 마이크·캔버스 트랙을 종료한다. 저장하지 않은 녹음이 있는 경우 페이지를 떠날 때 브라우저 확인을 요청한다. 마이크를 허용하지 않거나 녹음을 지원하지 않는 브라우저에서도 PNG 공유는 계속 사용할 수 있다.

사용자 결정: 유료 음성 인식·자동 채점·순위·회원 간 공개 녹음 목록은 보류한다. 이메일 회원가입 개시는 요청받았으나 운영 SMTP 미설정 확인 후 사용자가 토요일 미팅 이후 진행하기로 했다. 따라서 이번 배포에서는 가입 설정과 Supabase 설정을 변경하지 않는다.

검증: 녹음 수명주기·권한 취소·2분 제한·공유 취소·미지원 브라우저 등 8개 테스트. Chrome에서 테스트 소리로 실제 1080×1784 H.264/AAC MP4(약 9.6초)를 저장하고 두 트랙을 확인했다. 실제 마이크와 외부 메신저 전송을 자동으로 실행하지 않았다. 모바일 390px에서 가로 넘침 없이 녹음 종료 버튼이 보이는 것을 확인했다. iOS/Safari 실기기 녹음은 별도 검증이 필요하다.

## 단계별 생성·저장 UX (2026-11-06)

사진 준비 → 장면 만들기 → 저장·공유의 세 단계로 화면을 나눴다. 사진 단계의 주 버튼은 다음 단계로 이동하고, 장면 단계에서만 하나의 카드 생성 버튼을 표시한다. 첫 단계에서 Enter로 양식을 제출해도 유료 생성으로 이어지지 않는다. 장면 선택 화면은 사진 없이도 단계 메뉴에서 둘러볼 수 있지만 기존 사진·전송 동의·역할 확인 조건을 충족해야 생성된다.

모바일에서는 선택한 장면, 이전 단계, 생성/다음 버튼과 상태를 하단 고정 영역에 모았다. 본문 하단에는 여유 공간을 두어 내용을 끝까지 볼 수 있다. 장면 추천, 친구 사진, 대본 연습·인쇄는 접힌 영역에서 선택적으로 연다. 결과 화면에서는 이미지 카드/목소리 영상 중 선택한 형식의 도구만 보여주고, 녹음 중에는 형식 전환을 잠근다. 다른 단계로 나가면 마이크를 종료하며 완료된 카드를 다시 열 수 있다. 결과의 사진·장면 수정은 편집 단계로 돌아갈 뿐 자동으로 다시 생성하지 않는다.

데스크톱은 카드 미리보기 옆에 저장 도구를 배치하고, 모바일은 도구와 미리보기를 세로로 배치한다. 녹음 완료 후 저장·공유를 우선하고 다시 녹음/지우기는 보조 버튼으로 낮췄다. 생성 완료 시 상단 단계 메뉴까지 스크롤해 다음 행동을 보여준다.

검증: 배포 기준 전체 테스트 266개 통과. Chrome 390×844, 320×740에서 가로 넘침 없이 단계 이동·이미지/영상 전환·테스트 음성 녹음·MP4 저장을 확인했다. 1440×1000 데스크톱에서 양쪽 배치와 단일 생성 버튼을 확인했다. 로컬 시연과 합성 테스트 이미지를 사용해 추가 이미지 API 비용을 쓰지 않았다. 브라우저 확장의 파일 접근 권한이 없어 실제 파일 선택기 자동화는 실행하지 못했으며, 검수 전용 버튼으로 테스트 File을 선택 입력에 채운 뒤 실제 입력 처리 함수를 검수했다. 물리적 휴대전화 및 iOS Safari에서의 카메라·마이크 검증을 의미하지 않는다.

## 세 가지 장면 추천 방식 (2026-11-06)

첫 화면에서 하나를 명시적으로 선택한다: 내 사진 분위기 / 원하는 상황 / 랜덤. 첫 번째는 사용자가 승인한 사진의 표정·스타일 기반 장면 추천이며 실제 배우와 얼굴을 대조하거나 닮은 배우를 찾지 않는다. 상황 방식은 현재 등록된 대본의 상황 목록에서 선택한 장면을 안내하고, 랜덤은 서버에서 균등하게 무작위 선택한다. 두 방식은 사진·사진 전송 동의 없이 장면을 받을 수 있고 사진을 요청 본문에 넣지 않는다. 생성 카드에 자신의 얼굴을 넣으려면 그 다음 단계에서 사진과 기존 전송 동의를 받는다.

사진 업로드나 동의 체크만으로 추천을 자동 실행하던 동작을 없앴다. 사진 추천 버튼 클릭 시 한 번 요청한다. 초기 스타트업 기본 선택도 제거해 실제 추천과 기본 미리보기를 혼동하지 않도록 했다. 결과에는 사진 분위기 추천 / 선택한 상황 / 랜덤 선택을 각각 표시한다. 상황·랜덤은 OpenAI 호출 및 유료 추천 한도 소비 없이 처리한다. 사진 추천과 이미지 생성은 기존 동의·사진 검증·서버 한도를 유지한다.

최근 장면 ID만 해당 탭의 sessionStorage에 최대 300개 보관한다. 서버는 후보 목록과 대조한 유효 ID만 참고한다. 사진·랜덤 방식은 현재 순회에서 아직 보지 않은 후보를 먼저 사용하고, 전부 본 경우 직전 결과를 제외해 새 순회를 시작한다. 후보가 하나뿐이고 이미 보았으면 다른 후보가 없다는 안내를 돌려주며 사진 분석을 호출하지 않는다. 사진 추천 프롬프트와 JSON 선택 목록 양쪽에서 제외 후보를 제거하고, 모델이 제외된 장면을 반환하면 거부한다. 후보 입력 순서를 섞어 목록 맨 앞이 늘 유리하지 않게 한다. 원하는 상황의 직접 선택은 사용자 의도를 우선하므로 같은 상황을 다시 고를 수 있다.

추천 가능 범위는 원문 등록 대본·최소 길이·이미지·얼굴 영역을 충족하는 장면이며 현재 3개다. 등록된 상황만 선택 가능하고 새 대사를 임의로 만들거나 다른 10개 한 줄 인용 작품을 전체 대본처럼 추천하지 않는다. 화면에서 실제 후보 수를 표시한다.

검증: 배포 기준 273개 테스트 통과. 랜덤 9회에서 각 3개 순회와 직전 중복 제외, 사진 요청 후보 제한·잘못된 모델 결과 거부, 상황 선택, 사진·동의 없는 무료 경로와 유료 경로의 동의 보호를 확인했다. Chrome 로컬 시연에서 세 방식과 390/320px 가로 넘침을 확인했다. 사진 시연은 테스트 입력과 시연 응답을 사용했으며, 유료 모델의 추천 품질을 실제 사진으로 평가한 결과는 아니다. 사진 선택·동의만 했을 때 요청 0회, 버튼 클릭 후 1회인 것을 확인했다.

### 태그 추천

100개 모두 상황·감정·관계·연기 목적 네 범주와 한국어 키워드를 수동 분류했다. `scene-tags.cjs`가 허용 어휘·길이를 검증한다. 관리자에서 수정할 수 있고 저장 후 메타데이터가 유지된다. 기존 장면 분류는 `scene-metadata.json`, 신규 장면은 `licensed-scenes.json`에 있다.

‘원하는 상황’은 네 범주 중 원하는 조건과 선택 키워드를 조합한다. 조건 사이에는 AND를 적용하고 일치하는 장면·작품 수를 즉시 안내한다. 결과가 없으면 조건 완화를 안내하며 엉뚱한 대본을 대신 반환하지 않는다. ‘헤어짐→이별’, ‘회사→직장’, ‘우정→친구’ 등의 유의어는 목록 검색과 추천 키워드에 공통 적용한다. 같은 조건으로 다시 받으면 미열람 장면·다른 작품을 우선한다. 후보 작품을 먼저 균등 선택하므로 장면 수가 많은 작품에 추천이 쏠리지 않는다. 사진 추천에도 장면의 태그와 키워드를 전달한다. 무료 상황/랜덤 경로에서 유료 API 호출은 없다.

검증: 전체 284개 테스트 통과. 조건별 순회·작품 분산·빈 결과·잘못된 태그·관리자 메타데이터 보존을 확인했다. Chrome에서 갈등+연인 7개/3작품, 회사 키워드 14개/5작품, 서로 다른 작품으로 재추천, 빈 결과 버튼 차단, 320/390px 가로 넘침 없음 및 콘솔 오류 없음을 확인했다. 시연 환경에서 검증했으며 유료 모델 호출은 하지 않았다.


## 한국어 번역 연습 (2026-11-06)

재사용 허용 영어 대사 97개 전부에 한국어 연습 번역을 미리 저장한다. 원본 대사와 역할·순서를 유지하며 `translations-ko.json`의 sourceScript가 현재 원문과 정확히 일치할 때만 연결한다. 관리자 원문 수정 시 오래된 번역은 제거한다. `translationInfo`가 줄 수·형식을 검증한다. AI 번역·비공식 연습 번역이라고 표시하며 원문·번역 비교 보기를 제공한다.
